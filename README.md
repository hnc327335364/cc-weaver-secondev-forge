# CC Weaver Secondev Forge（Skill）

v0.3.0-rc.2 内部验证候选版 · 2026-10-30。内部支持九个按需模块，仍只安装一个 Skill。

一个 Skill，支持 E9/E10 需求分析、方案估算、资料查询、问题排查、授权开发和按需生成正式交付 HTML。知识资料与专业模块已随包提供，无需分别安装或阅读。

## 首次使用：安装一个 ZIP，再验证一次

三个工具使用从 GitHub 或 Gitee 发行页下载的同一版本仓库 ZIP，不需要运行 CMD，也不需要逐个安装内部模块。

**WorkBuddy：直接上传 ZIP。**

1. 打开「技能」，选择「添加技能」→「上传技能」。
2. 拖入或选择从发行页下载的版本 ZIP，按界面提示完成导入。
3. 在已安装技能列表中确认 `weaver-cc-assistant` 已显示并启用，再新建对话试用。

用户提供的 WorkBuddy 5.3.14 操作截图已显示该包安装并启用；这证明该实例的界面安装结果，不代表全部资料已核验或业务功能已验收，仍需完成下方正文试读。

**Codex / DSH：将 ZIP 交给 AI 安装。** 向具备本地文件访问能力的 AI 提供 ZIP 的本地路径并授权读取，发送：

> 请从我提供的本地路径安装 CC Weaver Secondev Forge 的仓库 ZIP，先定位归档第一层目录中的 SKILL.md。先按本单位安全要求检查压缩包与脚本；若必需的安全审查无法完成，请暂停并说明。再读取其中的 SKILL.md 和接入说明，核实当前工具的技能目录，展示唯一安装位置及写入范围，经我确认后完整安装。不要改工具配置，不要放入客户项目，不要直接覆盖已有版本；已有版本先说明备份和升级方案。没有所需文件权限或执行能力时，请明确说明。完成后指导我在新对话验证。

**安装后新建对话**，选择或调用 `CC Weaver Secondev Forge` / `weaver-cc-assistant`，发送：

> 请使用 CC Weaver Secondev Forge。E9 流程表单已有明细打开时不汇总，新增一行后才正常。先分析，不改代码；请列出实际读取的随包资料及判断依据。

能够加载 Skill、实际读取随包正文并给出有依据的分析，才表示当前工具接入有效。只显示技能名称或复述目录，不算完成验证。

## 以后直接提出任务

- 项目人员：请使用 CC Weaver Secondev Forge，梳理这份 E10 需求，列出需客户确认的问题，本次不编写代码。
- 开发人员：请使用 CC Weaver Secondev Forge，结合这些 E9 日志和代码定位原因，本次不修改文件。

说明 **E9/E10、目标和本次允许的操作**，附上相关脱敏材料即可。需要写代码时，明确允许修改的本地项目和范围；其他信息由 AI 按需询问。

## 遇到问题时

把界面提示或错误内容交给 AI 处理即可，不要关闭系统安全保护或反复尝试不同安装目录。WorkBuddy 上传 ZIP 不以 Python 为前提；随包本地安装器与完整检索需要 Python 3.9+，部分开发工具另需 Node.js，缺少时由 AI 说明能力限制和所需环境，不自动安装依赖。无法访问本地文件的聊天工具不能代为完成本地安装。各方式均须遵守所在单位安全要求，必需审查无法完成时暂停联系负责人。

升级时提供新版 ZIP，并说：“请安全升级 CC 助手，先预览差异和备份位置，确认后执行。”原生导入的旧版可能没有受管安装基线，AI 需另行说明备份和本地改动处理，不能直接覆盖。

详细步骤和项目、开发示例见 [使用说明](使用说明.md)，统一为 Markdown。

v0.3.0-rc.2 · 内部验证候选版。同一 ZIP 面向三种工具，WorkBuddy 优先原生导入，Codex/DSH 由 AI 核实后安装；正文读取、功能使用及不同系统的兼容性仍需分别验证。客户资料须脱敏，结果须复核，生产环境禁止执行随包远端操作工具。助手包不纳入客户代码仓库或交付物。

## 分发时

同事登录获授权的 GitHub/Gitee 私有仓库，从发行页选择指定版本并下载源码 ZIP，再导入技能。仓库根目录即完整 Skill，SKILL.md 与 README.md 位于同一层；不再额外要求维护者手工打包。使用说明仅保留 Markdown。当前归档结构按 WorkBuddy 官方要求整理，实际导入与正文试读仍需分别验证。

## 日常使用

直接提供任务和现有材料即可。简单改动按最小范围实现和验证；方案任务保持只读。已确认内容不必重复提供，关键资料不足时只补影响当前工作的部分。正式交付时明确提出“生成开发交付 HTML”，助手才加载随包模板与校验器。编译、模拟与客户现场结果分别说明。

例如：“这个函数空值显示异常，0需要保留。只改该函数并验证，不生成方案。”或“按当前列表筛选结果导出，请先核实取数入口和权限；没有依据的部分不要猜测。”
