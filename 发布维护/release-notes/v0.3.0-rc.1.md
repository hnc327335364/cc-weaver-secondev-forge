# CC Weaver Secondev Forge v0.3.0-rc.1

## 版本概述

本版为内部验证候选版，面向泛微 E9/E10 二次开发、项目与实施人员。重点改善简单任务处理、需求事实保留、列表导出取数约束和正式交付文档生成。变更整理日期为 2026-10-30，实际发布时间以发行页为准。

## 新增功能

- 接入正式交付文档内部模块，随包提供对象清单、HTML 模板及校验器，按任务需要调用。
- 增加主题入口与单文档方法定位能力，返回原文位置及后续读取参数。
- 增加 GitHub/Gitee 双平台发布工具，统一版本说明、源码提交及附件校验；仓库根目录即完整 Skill，使用者从发行页下载平台生成的版本 ZIP，无需维护者另行压缩。

## 优化改进

- 简单改动采用“核对相关实现、最小修改、针对性验证、简要交付”流程，避免默认展开完整项目流程或生成正式文档。
- 区分已确认事实、暂定条件、待验证事项及排除项；字段级调整不自动扩展到其他字段或阶段。
- E9 列表导出先核对实际查询链路、筛选条件、权限和分页，增加空结果、请求格式以及失败情形检查。
- 根 Skill 指令按任务分流，专业模块按需加载；保留共享知识资料，使用入口仍为一个 Skill。

## 问题修复

- 修正首次全量推送的超时设置，并在超时或中断时清理子进程；已通过本地成功、失败和超时检查。线上传输成功以远端实际提交为准。

- 修正本轮覆盖的检索参数异常处理，统一 UTF-8 与结构化错误输出；已通过本地正反例测试。
- 修正原规则对简单任务和正式交付触发边界不清的问题，并在离线案例中核对执行范围。
- 针对 E9 导出错误取数增加规则及知识页约束；本版未修改客户导出代码，不能据此认定现场故障已经修复。

## 兼容性与影响

- 产品展示名称统一为 CC Weaver Secondev Forge；安装标识及目录仍为 `weaver-cc-assistant`，保留原调用兼容性。
- 面向 WorkBuddy、Codex、DSH；各宿主及 Windows/macOS 的运行结果需分别验证，不以某一平台的结果代替其他平台验收。
- 使用说明统一为随包 Markdown，保留安装截图与应用示例；本地与仓库不再维护 Word/HTML/PDF 使用手册。本地仅保留最新可安装版本，历史版本通过 Git 标签和发行记录追溯。
- 本轮未修改原始资料、客户代码或用户全局规则。发布凭据不包含在 Skill 中。

## 验证结果

- 发布工具 13 项本地回归通过，覆盖无需手工 ZIP、发版说明完整性、重复发布、上传失败、附件损坏与进程清理。证据：`发布维护/tests/validation.json`。

- 包内 232 项本地测试通过；原工具和共享知识副本的逐文件 SHA256 核对未发现变更。证据归档编号：`20261030-实际使用优化/validation.json`、`package-tests-final.txt`。
- 四题同输入离线演练覆盖导出审查、需求方案、台账和简单函数；新版识别主要风险，简单函数 6 项断言通过。
- 使用说明由既有手册转为 Markdown，沿用安装步骤与项目、开发示例；截图作为图片附件保留。本次仓库 ZIP 的实际 WorkBuddy 导入尚未验证。
- 上述为本地与离线证据，不是三宿主、客户系统或生产环境验收结果。发布时核对两端源码提交和发版说明；若另附安装 ZIP，再核对文件一致性与下载 SHA256。源码发布成功不等于宿主安装验收。

## 已知限制

- 尚无可靠数据证明真实项目耗时、token 消耗或首次可用率改善，也未证明整体优于原版助手。
- E9 导出 ID 集合、权限、分页、失败回写及客户实际接口仍需现场验证。
- 三宿主与双系统代表场景验收尚未完成。本版保留候选标识，不建议将其作为已经全面验收的稳定版。
- 两个平台无法作为一个原子操作同时发布。中断可能留下草稿、上传中版本或单端已完成状态；恢复前须核对，不自动覆盖不同制品。

## 升级与回退

- 从发行页下载指定版本的源码 ZIP，通过宿主技能导入入口安装，避免混用不同版本目录；维护端本地只保留最新版。接收方的个性化配置需在升级前妥善保留。
- 升级后确认技能被识别，并分别验证一项简单修改和一项本项目典型任务；需要外部平台权限的操作仍由现场环境提供。
- 出现回归时停用新版，从历史发行页重新下载已验证可用的旧包；不要覆盖新旧混合文件。本轮尚无已验收的远端稳定 Release 可作为指定回退基线。
- 已发布版本不覆盖附件或改写发版说明。后续修复使用新版本号，旧制品及发版记录保留用于追溯。
