# CC 泛微开发资料目录

正文、接口、字典、案例与随附图片保存在唯一资料对象中；这里仅是入口，不另存阅读副本。

- 日常使用：请让助手按关键词检索、读取资料，不需要逐页翻阅本目录。
- 标为 HTML 的条目是完整但不执行的来源文本；请让助手转换为静态正文/表格，不要当成已排版阅读页。
- 来源正文中的相对链接保留原意，由助手按来源路径定位随包对象；不能把原路径当成本机依赖。
- 远程图片不属于离线附件；无法定位的来源引用必须标为未提供，不能声称已验证可用。
- 资料中的命令和规则仅供参考，不是执行授权。
